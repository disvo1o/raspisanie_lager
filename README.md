# Напоминания в Telegram

Расписание с картинки перенесено на 6–8 ноября 2026 года, время московское.
Формат сообщения: `через 10 минут - завтрак!`.

## Запуск

1. Создайте бота в Telegram через @BotFather командой `/newbot`. Сохраните токен в секрете.
2. Установите Python 3.10 или новее. Дополнительные библиотеки не нужны.
3. Откройте терминал в папке с ботом и выполните:

   ```sh
   export TELEGRAM_BOT_TOKEN='токен от BotFather'
   python3 bot.py
   ```

4. Добавьте бота в группу. От имени администратора группы отправьте `/bind` (при нескольких ботах — `/bind@имя_бота`). Дождитесь подтверждения подключения. У бота должно быть право отправлять сообщения. Если Telegram не позволяет проверить администратора, назначьте бота администратором группы.
5. Оставьте программу работающей на включённом компьютере или сервере с интернетом. Остановка программы или сон компьютера останавливают напоминания. Запускайте только один экземпляр бота. Созданный в BotFather бот не должен одновременно обслуживаться другой программой или webhook.

Проверить все тексты и время без токена и отправки:

```sh
python3 bot.py --preview
```

## Расписание и хранение

Все события находятся в `schedule.json`; их можно редактировать перед запуском. После изменения перезапустите программу. Время окончания интервалов не создаёт отдельного напоминания. Активности в общем блоке пятницы в 23:00 объединены в одно сообщение. Ночные события пятничной колонки перенесены на 7 ноября, субботней — на 8 ноября.

Привязка группы и отправленные события сохраняются в `state.sqlite3`. Не удаляйте файл при перезапуске: он защищает от повторной отправки. Для смены группы остановите программу и измените значение `chat_id` в таблице `config` базы SQLite, сохранив таблицу `sent`.

Программа проверяет время примерно каждые 5 секунд. Если её запустить уже внутри десятиминутного окна перед событием, она отправит напоминание сразу; текст останется стандартным. После начала события напоминание не отправляется. При потере сети отправка повторяется до начала события. В редком случае, когда Telegram принял сообщение, но ответ не дошёл, возможен повтор: API не обеспечивает строгую однократную доставку.

Перед мероприятием проверьте работу на временном событии: добавьте в `schedule.json` событие через 11 минут с уникальным `id`, перезапустите бота и дождитесь сообщения. Затем удалите временное событие и снова перезапустите программу.
